# F8.1 · Convenção de idioma

**Objetivo** — Domínio de volta ao português; convenções de código em inglês.

**Contexto necessário** — `Contexto/Decisoes.md` D26

## Por que existe

A F8 traduziu tudo e apagou o vocabulário do negócio junto. "Cartório" e "certidão" são conceitos jurídicos brasileiros; `DocumentType` não diz para um brasileiro o que `Documento` dizia. Esta fase corrige o alcance, não o princípio: código continua com convenção de indústria, o domínio volta a falar a língua de quem o entende.

## A regra

| Categoria | Idioma | Exemplos |
|---|---|---|
| Entidade e campo de domínio | **pt-BR** | `Cartorio`, `Documento`, `Pedido`, `Agendamento`, `nome`, `cep`, `tipoPessoa`, `documentoIdentificacao` |
| Valor de enum | **pt-BR** | `FISICA`, `JURIDICA`, `PENDENTE`, `EM_ANDAMENTO` |
| Rota REST | **pt-BR** | `/api/v1/cartorios`, `/documentos`, `/pedidos`, `/agendamentos` |
| Código de erro | **pt-BR** | `VALIDACAO`, `PAR_CARTORIO_DOCUMENTO_INVALIDO` |
| Pacote | **pt-BR**, plural, uma palavra | `cartorios`, `documentos`, `pedidos`, `agendamentos` |
| Verbo de método | **inglês** | `list`, `findById`, `create`, `update`, `delete`, `save` |
| Preposição | **inglês** | `toResponse`, `toEntity`, `fromRequest` |
| Sufixo estrutural | **inglês** | `Service`, `Repository`, `Controller`, `Mapper`, `Request`, `Response`, `Form` |
| Termo técnico genérico | **inglês** | `Page`, `Client`, `Handler`, `Validator`, `Config` |
| Texto de interface e mensagem | **pt-BR** | inalterado desde sempre |
| Comentário e Javadoc | **pt-BR** | |

Regra de bolso: **substantivo do negócio em português, tudo o mais em inglês.**

## Critério de aceite

- Backend sobe com `ddl-auto: validate`
- Migrations: **só V1–V4 e `R__seed.sql`**; `V5` não existe mais
- Comportamento idêntico à baseline **anterior à F8** (`comportamento-antes.txt`), inclusive códigos de erro e nomes de campo
- Métodos com verbo em inglês: `grep -rn "public .* listar\|buscar\|criar\|atualizar\|excluir" src/main/java` → vazio
- Toda tela continua em português

## Armadilhas

- O enum volta a `FISICA`/`PENDENTE`; sem apagar o `V5`, o `CHECK` em inglês recusa
- `sed` do BSD não tem `\b` — usar delimitador explícito ao trocar nome de pacote
- macOS não distingue caixa em nome de arquivo: renomear exige passo intermediário
