## Contrato do backend

```
GET/POST/PUT/DELETE  /api/v1/cartorios[/{id}]        ?page&size&nome
GET                  /api/v1/cartorios/{id}/documentos
GET/POST/PUT/DELETE  /api/v1/documentos[/{id}]       ?page&size
GET/POST/PUT/DELETE  /api/v1/pedidos[/{id}]
GET/POST             /api/v1/pedidos/{id}/agendamentos
GET/DELETE           /api/v1/agendamentos/{id}
PATCH                /api/v1/agendamentos/{id}/status
```

Campos JSON de volta ao português: `nome`, `cep`, `rua`, `numero`, `bairro`, `cidade`, `uf`, `documentos`, `documentoIds`, `totalDocumentos`, `totalAgendamentos`, `observacao`, `criadoPor`, `cartorioId`, `documentoId`, `tipoPessoa` (`FISICA`/`JURIDICA`), `nomeRazaoSocial`, `documentoIdentificacao`, `dataNascimento`, `documentoNome`, `cartorioNome`, `numero` (pedido). Status: `PENDENTE`/`EM_ANDAMENTO`/`CONCLUIDO`/`CANCELADO`.

Códigos de erro: `VALIDACAO`, `NAO_ENCONTRADO`, `PAR_CARTORIO_DOCUMENTO_INVALIDO`, `NOME_DUPLICADO`, `RECURSO_EM_USO`, `ERRO_INTERNO`, `REDE`.
