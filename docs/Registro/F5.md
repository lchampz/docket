## Decisões

**O ViaCEP nunca bloqueia o cadastro.** Três resultados explícitos — `ok`, `nao-encontrado`, `indisponivel` — e nenhum impede salvar. Autopreenchimento é conveniência, não pré-requisito.

Dois detalhes que o serviço impõe:
- Responde `200` com `{"erro": true}` para CEP inexistente, às vezes com a *string* `"true"`. Confiar no status HTTP preencheria o formulário com `undefined`.
- Digitação rápida dispara consultas sobrepostas, e a resposta lenta de um CEP antigo pode chegar depois e sobrescrever o endereço certo. Cada consulta tem id; resposta superada é descartada.

**Erro para campo virou decisão explícita.** Um `409` não traz `errors[]`, traz código e frase — e quem sabe a qual campo ele pertence é o formulário. Daí o mapa vir de fora, em `aplicarErroNoFormulario(erro, setError, { NOME_DUPLICADO: "nome" })`. O que não tem dono (`500`, queda de rede) a função devolve para virar toast.
